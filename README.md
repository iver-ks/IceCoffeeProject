# ICE Coffee

Веб-приложение кофейни, разработанное на Python с использованием фреймворка Bottle.  
Проект представляет собой сайт с информацией о кофейне, меню и контактами.

---

## Описание проекта

Сайт кофейни **ICE Coffee** включает:
- Главную страницу с меню
- Раздел «О нас» с описанием преимуществ
- Контактную информацию и карту

Проект реализован на основе шаблона веб-приложения Bottle в Visual Studio.

---

## Используемые технологии

- Python
- Bottle (веб-фреймворк)
- HTML5 / CSS3
- Git / GitHub

## ⚙️ Установка и запуск

1. Клонировать репозиторий:

git clone https://github.com/iver-ks/IceCoffeeProject.git

2. Перейти в папку проекта:

cd IceCoffeeProject

3. Создать виртуальное окружение:

python -m venv venv

4. Активировать окружение:
- Windows:

venv\Scripts\activate

5. Установить зависимости:

pip install -r requirements.txt

6. Запустить приложение:

python app.py
